# datos/

Datos de entrada del proyecto (hito **M1**, Consigna 1).

## Qué va acá
- Ficha del edificio (hospital tipo o real): superficie, camas, zonas, horarios.
- Datos tomados del artículo de Hospitecnia, con referencia a la sección o tabla de origen.
- Clima y condiciones de diseño (verano, y si alcanza invierno) y el estado muerto del análisis exergético (T₀, P₀).
- Condiciones interiores y ventilación de las zonas críticas, con la norma de origen.
- Tabla de hipótesis y supuestos.
- Tablas de propiedades de la cátedra usadas para contrastar CoolProp.

## Regla
Cada dato lleva **valor, unidad, fuente** y una marca de si es *dato* o *supuesto*. Lo que no tiene fuente no entra al cálculo.
