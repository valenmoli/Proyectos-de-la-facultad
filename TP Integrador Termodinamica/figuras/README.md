# figuras/

Representación gráfica (hitos **M2** a **M5**, Consignas 2 y 4).

## Figuras previstas
- Esquema del sistema: equipos, flujos de materia y transferencias de calor y trabajo.
- Diagrama P-h (y/o T-s) del ciclo de refrigeración.
- Carta psicrométrica con los procesos del aire: mezcla, enfriamiento y deshumidificación, recalentamiento.
- Diagrama de flujo de exergía (Grassmann) por alternativa.
- Comparativa Alt. A vs Alt. B.

## Regla
Las figuras se **generan desde `calculo/`**, no se dibujan a mano con números sueltos, para que siempre coincidan con los resultados. Formato PNG o SVG. El esquema del sistema puede ser un dibujo aparte, pero con los mismos estados de la tabla del cálculo.
